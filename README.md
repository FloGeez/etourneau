# etourneau

Florian Etourneau's brand: the amethyst starling, as files and code.

    npm i etourneau

- etourneau/tokens.css   colours, type, spacing and motion as --fe-* variables, light and dark
- etourneau/starling     the articulated starling: its drawing and the maths of each gesture
- etourneau/murmuration  the flock that draws the brand's shapes (on @flogeez/murmuration)
- etourneau/logo, /icons, /illustrations   the drawings, as SVG

See it on the plate (flogeez.github.io/etourneau) and in the guidelines. How it came to be: STORY.md.
